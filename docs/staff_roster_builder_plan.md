# 職員名一覧 自動作成ツール 設計案

シフトExcel（勤務表・実績）を渡すと、職員名一覧を自動で埋める仕組みの設計案。

実ファイル2本（`2607【気賀】` / `2607【萩丘ⅱ】`）を解析して構造を確認済み。
プロトタイプ `tools/staff_roster/parse_shift.py` は両ファイルで動作する。

---

## 1. 解析でわかったこと（最重要）

**時間計算を自作する必要はない。勤務表Excelがすでに集計済みの値を持っている。**

`管理用シート` の各職員行に、必要な数値がそのまま入っている：

| 列 | 内容 | 用途 |
|---|---|---|
| `B` | 職種（詳細） | 管理者 兼 サビ管 / サビ管 兼 生活支援員 / 生活支援員 / 世話人 / 夜間支援従事者 |
| `M` | 氏名 | 名簿の氏名 |
| `AE` | 常勤/非常勤 | 名簿の区分（`未入力`・空欄あり） |
| `CU` | 総労働勤務時間 (0:00-24:00) | 月間総労働時間 |
| `DE` | 日中勤務時間数 | **調査対象サービス分の時間** |
| `DL` | 日中配置換算（人工） | **常勤換算人数**（シートが計算済み） |
| `DW` | 職種（区分） | `生活支援員` / `世話人` ← 分類はこれが最も安定 |

さらに `生活支援員の勤務時間` 行・`世話人の勤務時間` 行に**シート自身の合計**があり、
抽出結果の検算に使える（後述）。

### 「調査対象サービス分に換算した人数」の正体

`マスタ設定` の勤務シフトコードは `日ⅰ①` `日ⅱ` `常夜ⅰ②` のように
**事業所を表す ⅰ / ⅱ の識別子**を持ち、`Y列`（日中時間内勤務時間数）に
**当該事業所分の時間だけ**が入る。他事業所（ⅰ）の勤務は 0。

つまり：

```
総労働時間           = CU = その職員が働いた全時間（他事業所分・夜間含む）
調査対象サービス時間 = DE = うち当該事業所の日中時間帯(6:00-22:00)分だけ
調査対象換算人数     = DL = DE ÷ 常勤所定労働時間
```

萩丘ⅱの「エー ミャッ ナンダー」が `CU=165h / DE=0h` なのは、
勤務がすべて `ⅰ`（萩丘ⅰ）のシフトコードだから。これで説明がつく。

## 2. 構成（3層）

```
シフトExcel ──▶ ①抽出 ──▶ ②名寄せ ──▶ ③照合・出力 ──▶ 職員名一覧.xlsx
                              │
                              └──▶ 検算CSV（職員1行）
```

### ① 抽出 `extract`

`管理用シート` から `B / M / AE / CU / DE / DL / DW` を読む。

**セル番地を決め打ちしない。**
`B列="職種"` かつ `M列` に "氏名" を含む行をヘッダーとして探し、そこから下を走査する。
見つからなければエラーで止める（黙って0件を返さない）。

**結合セルの前方補完が必須。** `B` `DW` は縦方向に結合されており、
openpyxlの素の読み取りでは先頭行以外が `None` になる。
`merged_cells.ranges` を展開して補完する。

対象行の条件は `DW ∈ {生活支援員, 世話人}`。
これだけで、管理者のみ・サビ管のみ・営業・凡例・合計行が自然に外れる。

### ② 名寄せ `normalize`

| ルール | 実装 |
|---|---|
| A・B欄／夜勤明けの分割行 | 氏名末尾の `①②③` `A/B` を除去して同一人物に統合 |
| 表記ゆれ | NFKC正規化＋空白除去（`松本錠二` と `松本　錠二` を同一視） |
| 派遣 | `野田正子(派遣)` のように括弧付き。括弧を除いて名寄せし、表示は原文のまま |
| 常勤/非常勤の食い違い | 統合時に常勤を優先（週40時間側に寄せる運用ルール） |
| `未入力`・空欄 | `マスタ設定 BK列` から氏名で補完。それでも不明なら**「区分不明」として出力し要確認にする** |
| タイミー | 氏名 `タイミー〜` で除外。時間は別枠で保持し注記 |

> **落とし穴**：`①` はNFKC正規化で `1` になる。
> 連番の除去は**正規化の後**に `[0-9AB]$` で行うこと。
> 先に `[①②]$` で消そうとすると効かない（プロトタイプで実際に踏んだ）。

### ③ 照合・出力 `verify` / `render`

**シート自身の合計行と突き合わせる。** これが品質の要。

```
抽出した職員別の合計（＋タイミー分） == 「生活支援員の勤務時間」行の CU / DE
```

一致すれば読み落としなし。不一致なら人が確認すべき異常がある。

出力：
- 職員名一覧.xlsx（テンプレートに openpyxl で転記、書式保持、15名超で列自動追加）
- 検算CSV（氏名 / 職種 / 区分 / 総労働 / 日中 / 換算 / 元の行番号 / 判定理由）

## 3. 照合が実際に見つけた不備

プロトタイプを実ファイルに当てたところ、**シートの合計と職員別の積み上げが合わない**箇所が出た。
原因はいずれも勤務表側の入力ミスだった。

| ファイル | 行 | 内容 |
|---|---|---|
| 萩丘ⅱ | 43 | 氏名が空欄なのに 総労働117h / 日中56h が入力済み。直下44行「花垣　洋①」と数値が完全一致 → **重複入力の疑い**。世話人合計が117h過大 |
| 気賀 | 38 | 氏名が空欄で 総労働2h が計上 → 合計が2h過大 |

名簿を作るだけのつもりが、**毎月の勤務表の入力ミス検出器**にもなる。
照合チェックは必ず入れる。

また、気賀では `生活支援員` 3名（諸井美智子・山本真由美・SAWTHANDARKYAW）の
常勤/非常勤が `未入力`・空欄で、マスタからも補完できなかった。
これは推測で埋めず「区分不明・要確認」として出す。

## 4. 運用形態の案

| | 内容 | 向き |
|---|---|---|
| **案A** | 既存の `勤務表チェック_Colab版` と同じくColabノートブック1本 | すぐ使いたい |
| **案B** | Pythonパッケージ＋CLI（GitHub管理・テスト付き）、Colabから1行で呼ぶ | 10施設を毎月回す |
| **案C** | Drive監視で全自動 | 現時点では過剰 |

### 推奨：案B のコアを作り、案A の薄いノートブックから呼ぶ

- 施設は10ある。パースの微修正は毎月出るので、テストが無いと直すたび他施設が壊れる
- 一方で実際の操作は「Driveに置いて1セル実行」でないと使われない
- 既存の `勤務表チェック/` フォルダ構成をそのまま使える

```
Drive/勤務表チェック/
├── 01_input_勤務表/     ← シフトExcelを置く
├── 02_output_結果/      ← 職員名一覧.xlsx ＋ 検算CSV
├── 03_master/
│   ├── 施設マスタ.xlsx              （既存）
│   └── 職員名一覧_テンプレート.xlsx  （新規・要提供）
└── 04_log/              ← 名寄せ・除外の判定ログ
```

## 5. 進め方

**Phase 1｜抽出＋照合＋検算CSV**（プロトタイプで到達済み）
2ファイルで動作確認済み。残り8施設に当てて崩れる箇所を潰す。

**Phase 2｜職員名一覧テンプレートへの転記**
テンプレート実物があれば着手できる。列の自動追加・書式保持まで。

**Phase 3｜全施設一括＋前月差分**
10施設をまとめて処理し、入職・退職・区分変更の差分も出す。

## 6. 確認したいこと

1. **職員名一覧のテンプレート実物** — これが無いとPhase 2に進めない
2. **常勤所定労働時間の基準** — `DL` の割る数は 168h だが、シート注記は「31日＝177時間」。
   名簿に載せる換算値は `DL` をそのまま使ってよいか、177hで計算し直すか
3. **タイミー・派遣の扱い** — 自治体提出上、常勤換算に含めるか
4. **区分不明者の扱い** — 気賀の3名のように `未入力` の場合、どう埋めるのが正か
