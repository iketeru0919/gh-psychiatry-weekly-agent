## Chapter 0：はじめに

### 0-1. この資料の目的

この資料は、障がい者グループホーム（以下 GH）事業における以下の3役職について、
**役割・目的・求められること・評価基準・行動基準**を体系的に整理したものです。

- **エリアマネージャー（AM）**
- **エリアディレクター（AD）**
- **シニアマネージャー（SM）**

---

### 0-2. 役職の階層

```
経営層（社長・役員）
        ↓
シニアマネージャー（SM）
        ↓
エリアディレクター（AD）　← 複数グループ会社横断
        ↓
エリアマネージャー（AM）
        ↓
管理者 / サービス管理責任者（サビ管）
        ↓
支援職員
```

---

### 0-3. 3役職を一言で表すと

| 役職 | 一言で言うと | 見る範囲 |
|---|---|---|
| エリアマネージャー（AM） | **施設を良くする人** | 自分の担当施設 |
| エリアディレクター（AD） | **施設が良くなる仕組みを作る人** | 複数AM・複数施設・複数グループ会社 |
| シニアマネージャー（SM） | **事業全体が利益を出し、安定運営できる構造を作る人** | 事業全体・経営層 |

---

### 0-4. エリアディレクターの特記事項

> **エリアディレクターは、単に担当施設数が増える役職ではありません。**

エリアディレクターは、**複数のグループ会社にまたがって**、共同生活援助・短期入所の
運営基準・KPI・加算・請求・人員・支援品質を横断的に整える役職です。

具体的には、以下をすべて含む横断管理が求められます。

- ラシエル / イノベル（複数グループ会社）
- 共同生活援助・短期入所の複数施設
- 複数エリアマネージャー
- 複数管理者・複数サビ管
- 本部・管理部・請求部門・人事部門との連携

AMが「自分の担当施設を深く見る人」であるとすれば、
ADは「**会社をまたいでも同じ基準で運営状態を比較し、改善できる状態を作る人**」です。

## Chapter 1：障がい者GH事業の収益構造

> **この章を先に理解することが重要です。**
> AM・AD・SMの役職差は、結局「どの範囲の収益構造を見て、どこまで動かすか」の違いだからです。

---

### 1-1. GH・SSの売上構造

| 売上区分 | 内容 | 影響するKPI |
|---|---|---|
| GH基本報酬 | 障害支援区分・定員に応じた日額報酬 | 入居率・平均区分 |
| GH各種加算 | 重度障害者支援加算・強度行動障害加算・夜間支援加算 等 | 加算算定率・区分 |
| 短期入所（SS）基本報酬 | 利用日数に応じた日額報酬 | SS稼働率・利用日数 |
| SS各種加算 | 医療連携加算・福祉専門職員配置等加算 等 | 加算算定率 |
| 食費等の実費 | 入居者から徴収する実費 | 入居者数 |
| その他 | 光熱費・家賃負担等 | 入居者数 |

---

### 1-2. 収支に影響する主要KPI

```
売上に効くKPI
├── 入居率（定員に対する入居者数の割合）
├── 平均区分（障害支援区分の平均：区分が高いほど単価が上がる）
├── 加算算定率（取れる加算のうち、実際に算定できている割合）
├── SS稼働率（短期入所の稼働日数の割合）
├── 空床日数（退去〜次の入居までの期間）
└── 入院・外泊日数（入院等は報酬が減算される）

費用に効くKPI
├── 人件費率（売上に対する人件費の割合）
├── 派遣費（派遣スタッフへの支払い）
├── タイミー費（スポット人件費）
├── 夜勤人件費（夜間支援員の給与）
└── 請求乖離件数（実績と請求のズレ → 売上漏れリスク）
```

---

### 1-3. 費用構造

| 費用区分 | 主な内容 | 固定/変動 |
|---|---|---|
| 常勤人件費 | 正社員・契約社員の給与・社保 | 固定 |
| 非常勤人件費 | パートタイム職員の給与 | 半固定 |
| 夜勤人件費 | 夜間支援員（宿直・夜勤手当含む） | 半固定 |
| 派遣費 | 派遣スタッフへの支払い | 変動 |
| タイミー費 | スポット人材の費用 | 変動 |
| 家賃・リース | 施設の賃料・設備リース | 固定 |
| 水光熱費 | 電気・ガス・水道 | 半変動 |
| 食材費 | 食事提供にかかる食材 | 変動 |
| 修繕費 | 設備修繕・消耗品 | 変動 |
| 管理費 | 本部管理費等 | 固定 |

---

### 1-4. GHで起きやすい赤字要因の分類

赤字・低利益施設が発生するとき、必ずどれかの類型に当てはまります。

| 類型 | 主な症状 | 確認すべき数字 |
|---|---|---|
| **稼働不足型** | 入居者が少ない・空床が多い | 入居率・空床日数・退去から入居までの期間 |
| **SS未活用型** | 短期入所がほぼ動いていない | SS稼働率・利用日数・契約者数 |
| **加算不足型** | 取れる加算が取れていない | 加算算定率・区分変更候補者数 |
| **区分不足型** | 区分が実態より低い | 平均区分・区分変更申請状況 |
| **人件費過多型** | 常勤配置が重い・シフト効率が悪い | 人件費率・常勤比率 |
| **派遣依存型** | 派遣費が高止まりしている | 派遣時間・派遣費・採用状況 |
| **タイミー依存型** | スポット人件費が膨らんでいる | タイミー費・欠員状況 |
| **固定費過多型** | 家賃・管理費が重い | 固定費率・損益分岐点 |
| **請求漏れ型** | 実績と請求にズレがある | 請求乖離件数・返戻件数・未請求数 |
| **管理者機能不全型** | 管理者が施設を機能させられていない | 管理者面談記録・職員定着率・事故件数 |

---

### 1-5. KPIとPLの関係（概念図）

```
KPIの動き → PLへの影響

入居者 +1名      →  月 約○万円 売上増
SS利用 +10日    →  月 約○万円 増収
重度加算 +1名   →  月 約○万円 増収（区分・加算種別による）
区分 3→4 変更   →  月 約○万円 報酬差額
空床 -10日       →  約○万円 機会損失の圧縮
派遣 -50時間     →  月 約○万円 費用削減（年間 約○万円）
請求漏れ 0件化  →  年間 約○万円 収益改善
```

> **AMはKPIを追う人。ADはKPIをPLに翻訳できる人。SMはPLを見て資源配分を決める人。**

## Chapter 2：エリアマネージャーの役割

---

### 2-1. 役割の定義

エリアマネージャーは、**自分の担当施設に直接関わり、現場の課題を早期に見つけ、管理者・サビ管・職員を動かして改善する人**です。

- 担当範囲：自分の担当施設（直接管理）
- 仕事の重心：**直接改善・現場介入**
- 求められる時間軸：週次〜月次

---

### 2-2. 目的

> 担当施設の運営状態を改善し、**入居率・AU・SS・加算・人員・支援品質を安定させること**。

現場に最も近い立場として、施設ごとの問題を早期に見つけ、スピーディーに改善することが最大の役割です。

---

### 2-3. 主な業務・役割

#### ■ 稼働管理
- 入居率の確認と改善（退去予測・待機者案内・空床管理）
- AU（在宅入居日数）の確認
- SS（短期入所）稼働率の改善
- 空床期間の最短化

#### ■ 財務・加算管理
- 加算・区分変更の進捗確認
- 請求漏れ・受給者証期限の確認
- 派遣・タイミー費用の確認

#### ■ 人員管理
- 派遣・タイミー・採用状況の把握
- 職員の過不足・シフト状況の確認

#### ■ 管理者・サビ管支援
- 管理者・サビ管への定期的な助言・面談
- 管理者が機能しているかの確認
- サビ管が支援課題を整理できているかの確認

#### ■ リスク管理
- 事故・苦情・コンプライアンス案件への初動対応
- 上司への正確な施設状況報告

---

### 2-4. 目指すもの（ゴール状態）

AMとして達成すべき「施設の安定状態」は以下です。

```
✅ 入居率が安定している（定員に対して高稼働を維持）
✅ SS稼働が改善している
✅ 管理者が施設を機能させている
✅ サビ管が支援課題を整理・把握できている
✅ 派遣・タイミー依存が適正範囲に収まっている
✅ 加算・区分変更の漏れが少ない
✅ 事故・コンプラの初動が早い
✅ 上司に正確な報告ができている
```

---

### 2-5. 果たすべきもの（成果責任）

AMが果たすべきは**担当施設の成果責任**です。

具体的には、以下を「自分の言葉で」明確にできる状態が求められます。

| 問い | AMが答えられるべき内容 |
|---|---|
| この施設の最大課題は何か | 稼働率・加算・人件費・管理者・サビ管のどこか |
| なぜ数字が悪いのか | 構造的な原因を分解して説明できる |
| 管理者に何をさせているのか | 具体的な指示内容と期限 |
| いつまでに何を改善するのか | 数値目標と期限が明確 |
| 改善しない場合どう介入するか | エスカレーションの判断基準を持っている |

---

### 2-6. 会社から求められていること

| 求められること | 具体的な内容 |
|---|---|
| 担当施設のKPI改善 | 入居率・SS・加算・区分・人件費を改善する |
| 早期把握 | 空床・低稼働・人員不足を放置しない |
| 請求・加算の管理 | 加算漏れ・請求漏れ・受給者証期限を管理する |
| リスク管理 | 事故・コンプラを早期把握し、初動を素早くとる |
| 正確な報告 | 上司が判断できる情報を正確に上げる |
| 現場行動 | 課題を見つけたら具体的な改善行動に落とす |

> **一言で：「担当施設を任せられる人」**

---

### 2-7. AMに求められるPL視点

AM段階でも、PL（損益）への理解は必要です。
ただし、AMに求められるレベルは**「担当施設の収支悪化要因を見つけること」**です。

#### AMが見るべきPL視点

| KPIの悪化 | PLへの影響（AMとして理解すべき内容） |
|---|---|
| 入居率低下 | GH基本報酬・加算売上が下がる |
| AU低下 | 入院・外泊分の報酬が減算される |
| SS稼働低下 | 短期入所売上が下がる |
| 加算漏れ | 本来取れたはずの収入が取れていない（機会損失） |
| 派遣・タイミー増加 | 変動費が膨らみ、利益が圧迫される |
| 空床期間の長期化 | 日割り報酬が発生しない日が続く |
| 請求漏れ・返戻 | 実績と請求のズレが直接損失になる |

---

### 2-8. シニアマネージャーからAMに求められること

| SMからの期待 | 具体的な内容 |
|---|---|
| 現場の状況を正確・早期に報告する | SM・ADが判断するための情報を上げる |
| 管理者・サビ管を機能させる | AMが直接動くのではなく、管理者を通じて施設が動く状態を作る |
| 問題を放置しない | 課題があればADへ即時エスカレーション |
| エスカレーション判断ができる | 「自分で解決できる課題」と「上に上げる課題」を区別する |

---

### 2-9. AMのNG行動

> これをやっていると、いつまでもAMの壁を越えられません。

```
❌ 数字を見ずに感覚・経験則で判断する
❌ 管理者の報告をそのまま上司に上げる（自分で確認・分析しない）
❌ 空床・低稼働・SS低稼働を「様子見」で放置する
❌ 加算・請求・受給者証を「管理者任せ」にする
❌ 事故・コンプラへの初動が遅い
❌ 施設課題を「人が足りない」だけで終わらせる（原因を分解しない）
❌ 問題の原因を「管理者のせい」で終わらせる（自分の介入方法を問わない）
```

## Chapter 3：エリアディレクターの役割

---

### 3-1. 役割の定義

エリアディレクターは、**複数グループ会社にまたがって、複数のAM・管理者が同じ水準で成果を出せる仕組みを作り、属人的な運営を標準化する人**です。

- 担当範囲：複数AM・複数施設・**複数グループ会社**・横断課題
- 仕事の重心：**標準化・横展開・AM育成・仕組み化**
- 求められる時間軸：月次〜四半期

> **ADはAMより担当施設が増えるのではなく、「施設が良くなる仕組みを作る立場」に変わります。**

---

### 3-2. 複数グループ会社横断の意味

ADの担当範囲には、以下がすべて含まれます。

```
AD の横断対象

グループ会社
├── ラシエル（共同生活援助・短期入所）
└── イノベル（共同生活援助・短期入所）

役職層
├── 複数エリアマネージャー
├── 複数管理者
└── 複数サービス管理責任者（サビ管）

連携部門
├── 本部
├── 人事部門
├── 管理部
└── 請求部門
```

ADに求められるのは、**会社をまたいでも同じ基準で運営状態を比較し、改善できる状態を作ること**です。

---

### 3-3. 目的

> 複数施設・複数AMの成果を安定させ、**属人的な運営を標準化すること**。
> AMや管理者が「同じ水準で成果を出せる状態」を作ること。

---

### 3-4. 主な業務・役割

#### ■ AMマネジメント
- 複数AMの進捗確認
- AMごとの判断基準の統一
- AM報告の質を揃える（フォーマット・内容・粒度）
- AMが育つための1on1・面談の型づくり

#### ■ 横断KPI管理
- 複数施設の入居率・SS・加算・人件費を横断的に比較
- 施設間のばらつきを見つける
- 改善施設と課題施設の差異分析

#### ■ 標準化・仕組み化
- 入居営業・SS営業の標準導線の作成
- 加算・区分変更の確認フロー作成
- 請求・受給者証チェックの標準化
- 管理者面談・サビ管面談の型づくり
- 低稼働施設の改善手順の作成

#### ■ 横展開・改善モデル
- 成功施設の取り組みを他施設へ横展開
- 派遣・タイミー削減の改善パターン作成
- 事故・コンプラ再発防止の仕組み化

#### ■ 上位連携
- 本部・人事・管理部・請求部門との調整
- シニアマネージャーへ判断材料を整理して上げる

---

### 3-5. 目指すもの（ゴール状態）

> **「誰が担当しても、一定水準で施設運営が回る状態」**

```
✅ AMごとの判断基準が揃っている
✅ 管理者が見るべき数字が統一されている
✅ SS営業のやり方が施設ごとに属人化していない
✅ 加算候補者が自動的に拾える仕組みがある
✅ 受給者証期限・請求漏れが早期に分かる
✅ 派遣費・タイミー費が悪化した施設がすぐ分かる
✅ 低稼働施設に対する改善手順が決まっている
✅ 管理者・サビ管の育成方法が標準化されている
✅ 成功事例が他施設へ展開されている
```

---

### 3-6. 果たすべきもの（成果責任）

ADが果たすべきは**横断改善・標準化・AM育成・PL改善の仕組み化**です。

AMが個別施設を見るのに対して、ADは「構造」で見ます。

| AMの見方（個別対応） | ADの見方（構造課題として捉える） |
|---|---|
| 西浅田のSS稼働が低い | なぜSS低稼働施設が複数発生するのか |
| 南中丸の入居率が低い | 空床改善の標準手順はあるか |
| 高丘の派遣削減が進まない | 派遣削減できる施設との構造差は何か |
| 気賀の退去後の空床期間が長い | 退去発生時の待機者案内フローは標準化されているか |
| 加算が取れていない施設がある | 加算候補者を自動的に拾う仕組みはあるか |
| 人件費が高い | 人員配置・シフト・派遣依存のどこに構造問題があるか |

> **ADは、個別課題を構造課題に変換し、再発防止・横展開・標準化まで持っていく役割です。**

---

### 3-7. 会社から求められていること

| 求められること | 具体的な内容 |
|---|---|
| AM育成 | AMが自走できる状態を作る |
| 判断基準の統一 | AMごとに報告・判断の質がばらつかないようにする |
| 改善モデルの作成 | 低稼働・派遣費高騰・加算漏れの改善パターンを作る |
| 横展開 | 成功施設の取り組みを他施設・他グループ会社へ展開する |
| 仕組み化 | 加算・請求・受給者証管理を標準化する |
| 収益改善への翻訳 | 現場課題をPL・収益課題として説明できる |
| SM連携 | SMが判断しやすい情報に整理して上げる |

> **一言で：「複数AM・複数施設を安定させる実務統括者」**

---

### 3-8. ADに求められるPL視点

> **ADになると、単にKPIを見るだけでは不十分です。**
> **「KPI改善をPL改善に変換できること」が求められます。**

#### ■ KPIをPLに翻訳する力

| KPI改善の報告 | ADとしてのPL翻訳 |
|---|---|
| 入居者が1名増えた | 月 ○万円の売上増見込み |
| SS稼働が10日増えた | 月 ○万円の増収見込み |
| 派遣を50時間削減した | 月 ○万円・年間 ○万円の費用削減 |
| 重度加算が1名算定できた | 月 ○万円・年間 ○万円の増収 |
| 空床期間を10日短縮した | 機会損失を ○万円 圧縮 |
| 区分変更（3→4）が通った | 月 ○万円の報酬差額改善 |

#### ■ ADで必要なPL力（3段階）

```
Step 1：施設別PLを読む力
  → どの施設が赤字か・なぜ赤字か・どの費目が重いかを読む

Step 2：収支悪化要因を分解する力
  → 「赤字」を稼働不足型・人件費過多型・加算不足型等に分類する

Step 3：改善策を金額で示す力
  → 「入居者1名増で月○万円増収・派遣費削減で年間○万円改善」と具体的に示す
```

---

### 3-9. シニアマネージャーからADに求められること

#### ① 現場状況を整理して上げる

SMは全施設を細かく見切れません。ADに求められるのは、SMが判断できる形に情報を整理することです。

```
SMが知りたいこと（ADが整理して上げるべきこと）

・どの施設が危ないか
・なぜ危ないか（KPI上・PL上の問題は何か）
・どのAMが対応すべきか
・現場で解決できる課題はどれか
・SM判断が必要な課題はどれか
```

#### ② KPIだけでなくPL影響を添える

SMが知りたいのは単なる現場状況だけではありません。

| 悪い報告例（AM水準） | ADとしての報告例 |
|---|---|
| 西浅田はSS稼働が低いため、営業を継続します。 | 西浅田はSS稼働率が低く、月次売上に影響しています。7月はSS利用回数を○日増やすことで月○万円程度の増収を見込みます。高稼働施設の営業導線を横展開します。 |

#### ③ 相談ではなく、選択肢を出す

```
❌ 「どうしましょうか？」

✅ 「選択肢はA・B・Cです。
    私はAが妥当だと考えます。
    理由は○○です。
    ご判断をお願いします。」
```

#### ④ 現場と経営の橋渡しをする

| 方向 | ADの役割 |
|---|---|
| 現場 → 経営 | 現場の困りごとを経営課題に変換して上げる |
| 経営 → 現場 | 経営方針を現場が実行できる粒度に落とす |
| 横連携 | 管理部・人事・請求部門と現場の間を調整する |

#### ⑤ AM・管理者を育てる

```
✅ AMが施設状況を正確に報告できるようにする
✅ AMがPL影響を考えて動けるようにする
✅ 管理者が数字を見られるようにする
✅ サビ管が支援課題を整理できるようにする
✅ 問題施設の管理者を改善に向かわせる
✅ 後任候補者を見つけ・育てる
```

#### ⑥ SMの負担を減らす

ADが機能することで、SMは細かい現場対応から離れ、事業全体の判断に集中できます。

```
ADが担う「SMの負担軽減」
├── 現場の一次整理（SMが見る前に情報を整理する）
├── 課題の優先順位づけ（何が急ぎで何が後でいいかを判断）
├── PL影響の整理（影響額を添えて上げる）
├── 対応状況の進捗管理（SMが追わなくてよい状態を作る）
└── 判断が必要なものだけを上げる（細かい報告でSMの時間を取らない）
```

---

### 3-10. ADのNG行動

```
❌ 自分で全部解決しようとする（AM・管理者を育てず、自分が動く）
❌ AMを育てず、管理者へ直接指示し続ける
❌ 個別対応で終わる（標準化・横展開まで持っていかない）
❌ KPI改善をPL改善に翻訳できない（「稼働が上がりました」で終わる）
❌ 施設ごとの差を構造分析しない
❌ SMへ「どうしましょうか」と丸投げする
❌ グループ会社ごとに異なるやり方を放置する
❌ 仕組みを作るが、運用定着まで確認しない
```

## Chapter 4：シニアマネージャーの役割

---

### 4-1. 役割の定義

シニアマネージャーは、**事業全体の収益・組織・人材・リスク・成長戦略を設計し、経営層への提言を担う人**です。

- 担当範囲：事業全体・複数エリア・経営層連携
- 仕事の重心：**収益設計・組織設計・経営判断**
- 求められる時間軸：半期〜年度・中期

> ADが「複数施設・複数AMの成果を安定させる人」であるなら、
> SMは「事業全体として何を優先し、どこに人・お金・時間を使うかを判断する人」です。

---

### 4-2. 目的

> 事業全体の収益・組織・人材・リスク・成長戦略を設計することで、
> **事業が継続的に利益を出し、組織として安定運営できる状態**を作ること。

---

### 4-3. 主な業務・役割

#### ■ 事業全体の設計
- 事業全体のKGI・KPI設計
- 施設別・エリア別PLの確認
- 赤字施設の改善方針決定
- 人件費・派遣費・タイミー費の適正化方針

#### ■ 組織・人材
- AM・ADの配置・育成・評価
- 管理者・サビ管の組織設計
- 管理者交代・昇格の判断
- 後継者育成

#### ■ 成長・投資
- 新規開業方針への関与
- 事業拡大の優先順位判断
- 施設別の投資対効果評価

#### ■ リスク統制
- 重大事故・行政リスク・コンプライアンスの統括
- 事業継続計画（BCP）の方針策定

#### ■ 経営連携
- 本部・人事・管理部・請求部門との方針調整
- 社長・経営層への提言

---

### 4-4. 目指すもの（ゴール状態）

```
✅ 事業全体の収支が改善している
✅ 赤字施設が計画的に改善されている
✅ 低稼働施設の改善モデルが機能している
✅ AM・ADが自走して育っている
✅ 管理者候補が計画的に育成されている
✅ 事故・コンプラリスクが管理されている
✅ 新規開業後の立ち上がりが安定している
✅ 加算・請求・区分変更が仕組み化されている
✅ 経営層が判断できる資料が定期的に上がっている
```

---

### 4-5. 果たすべきもの（成果責任）

SMが果たすべきは**事業全体の成果責任**です。

ADまでは「複数施設の成果を安定させる」役割ですが、SMはさらに、以下のすべてを判断します。

| 判断領域 | SMが判断すべき内容 |
|---|---|
| 施設優先順位 | どの施設を重点改善するか |
| 人員配置 | どのエリアにAM・ADを厚く置くか |
| 人材 | どの管理者を育成・交代すべきか |
| 加算方針 | どの加算を重点的に取りにいくか |
| 投資・開業 | どの新規開業を優先するか |
| リスク | どのリスクを経営層に上げるか |
| 構造改革 | どの施設は構造的に見直すべきか |

> **SMは「運営改善をする人」ではなく、「組織と収益の設計者」です。**

---

### 4-6. 会社から求められていること

| 求められること | 具体的な内容 |
|---|---|
| 事業全体の利益改善 | 施設別・エリア別PLを改善する |
| 赤字施設の方針決定 | 原因を分解し、改善か撤退かを判断する |
| 組織体制の安定化 | AM・AD・管理者が機能する組織を作る |
| AM・AD層の育成 | 次の管理職候補を計画的に育てる |
| 経営提言 | PLを踏まえた改善提案を経営層に上げる |
| リスク統制 | 重大リスクの早期発見と組織的対応 |
| 判断支援 | 新規開業・事業拡大の判断に必要な情報を提供する |

> **一言で：「事業全体を経営目線で動かす人」**

---

### 4-7. SMに求められるPL視点

> **ADが「KPIをPLに翻訳する人」だとすれば、SMは「PLを見て事業全体の資源配分を決める人」です。**

SMが判断するPL視点の例：

```
・どの赤字施設を先に改善するか（優先順位）
・どの施設は稼働改善で黒字化できるか（稼働型改善）
・どの施設は人件費構造を変えるべきか（コスト構造改革）
・どの施設は管理者交代が必要か（組織的改革）
・どの施設は新規投資に値するか（投資判断）
・どのエリアにAM・ADを厚く置くべきか（資源配分）
・どの加算を重点的に取りにいくべきか（収益方針）
・派遣費削減をどの施設から着手するか（優先順位）
```

> **SMに必要なのは、PLを見て事業全体の資源配分を決める力です。**

---

### 4-8. AD・AMに求めるもの（SMの視点から）

| 役職 | SMがAD・AMに求めること |
|---|---|
| AD に求めること | 現場を整理し、PL・KPI・リスクの観点で判断材料に変えて上げること |
| AM に求めること | 現場の状況を正確に早期に把握し、AMとしての成果責任を果たすこと |

---

### 4-9. SMのNG行動

```
❌ 現場の実態を見ずにPLだけで判断する
❌ 赤字施設の原因を分解しないまま改善方針を出す
❌ AM・ADの育成を放置する（個人任せにする）
❌ 事業全体の優先順位を示さない（現場が何を優先すべきか分からない）
❌ 人員配置・投資判断を曖昧にする
❌ リスク案件を個別対応で終わらせる（構造化・再発防止まで持っていかない）
❌ 経営層への報告が「状況説明」だけになる（提言がない）
```

## Chapter 6：AM→AD→SMへの移行で変わること {#chapter-6amadsm移行}

---

### 6-1. AM → ADへの移行：仕事の重心の変化

| 今までの重心（AM） | 今後の重心（AD） |
|---|---|
| 自分が施設状況を確認する | AMが同じ基準で施設を見られるようにする |
| 自分が管理者に助言する | 管理者が自分で課題を拾えるようにする |
| 自分がサビ管面談をする | サビ管が支援課題を報告できるようにする |
| 自分が課題を見つけて動く | KPIで異常が分かる仕組みを作る |
| 施設ごとに個別対応する | 再発しない標準フローを作る |
| 状況報告をする | 提言型報告（原因・対策・PL影響・判断依頼）をする |
| 施設の問題を解決する | 同じ問題が他施設で起きない仕組みを作る |

---

### 6-2. AD → SMへの移行：さらに変わること

| ADとしての力 | SMへ移行する際に伸ばすべき力 |
|---|---|
| 施設KPI管理 | PL・利益構造の理解と判断 |
| 管理者・サビ管支援 | AM・AD層の育成と評価 |
| 個別課題整理 | 事業全体の優先順位判断 |
| 標準化ツール作成 | 運用定着・制度化・評価への組み込み |
| 上長報告 | 経営判断に必要な提言 |
| 複数施設の改善設計 | 事業全体のPL・組織・人材・リスクを設計 |

---

### 6-3. 「自分が動く」から「人を通じて動かす」へ

```
AM段階：自分が現場に入って改善する
    ↓
AD段階：AMや管理者が自走して改善できる仕組みを作る
    ↓
SM段階：AD・AMが組織として機能する構造を設計する
```

> **この移行ができないと、担当範囲が広がっても「スーパーAM」のままになります。**

## Chapter 7：役職別・報告の違い（実例）{#chapter-7役職別報告の違い実例}

同じテーマに対して、AM・AD・SMが「どう違う報告をするか」を具体的に示します。

---

### テーマ①：SS稼働が低い施設がある

#### AMの報告
```
現状：西浅田のSS稼働率が低い状態が続いています。
原因：問い合わせ・見学件数が少ない状況です。
対応：相談支援事業所への営業を継続し、見学案内を強化します。
期限：翌月中に稼働率80%を目標とします。
```

#### ADの報告
```
現状：複数施設でSS稼働に差が生じており、西浅田・南中丸で低稼働が続いています。
原因：営業先のリスト・訴求文面・レスパイト需要の取り込み方法に施設間のばらつきがあります。
対策：高稼働施設（高丘・上西郷）の営業パターン・契約導線を低稼働施設へ横展開します。
PL影響：SS利用○日増で月○万円程度の増収見込みです。
SM判断事項：営業対象先の優先順位・管理者評価項目への反映について確認をお願いします。
```

#### SMの報告・提言
```
現状：SS稼働のばらつきが施設間の収益差になっています。
分析：稼働が取れている施設は営業導線と管理者の動き方が明確です。課題施設は属人的な動き方になっています。
方針：SSを収益補完の柱として全施設共通の営業フローを整備します。
判断依頼：重点施設の選定・営業リソースの配置・管理者評価への組み込みについてご判断ください。
中期影響：SS全体稼働率が○%改善すると、年間○万円の増収見込みです。
```

---

### テーマ②：派遣費が高止まりしている

#### AMの報告
```
現状：高丘の派遣費が先月比で増加しています。
原因：夜勤対応のスタッフが不足しており、派遣で補っています。
対応：採用活動を強化し、パートを増やす方向で動いています。
```

#### ADの報告
```
現状：複数施設で派遣費の高止まりが続いています。
原因分析：
  ・採用が追いついていない施設（高丘・南中丸）
  ・シフト設計の非効率がある施設（気賀）
  ・定着率が低く補充が追いつかない施設（西浅田）
対策：施設ごとに原因が異なるため、個別の改善方針を設定します。
PL影響：現状の派遣費水準が続くと、3施設合計で月○万円・年間○万円の過剰コストになります。
SM判断事項：採用費の一時的な追加投資と、派遣費削減の着手施設の優先順位についてご判断ください。
```

#### SMの報告・提言
```
現状：派遣費の高止まりが事業全体の利益を圧迫しています。
構造分析：
  ・稼働率が低い施設ほど派遣依存が高い傾向があります
  ・採用力に差がある（管理者の採用関与度と相関）
  ・定着率が低い施設は離職補充コストが膨らんでいます
方針：採用・定着・シフト設計の3軸で構造を変える必要があります。
投資判断：採用費に短期集中投資することで、半期以内に派遣費を○万円削減できる試算です。
判断依頼：採用費予算の追加可否・管理者育成施策の優先順位についてご判断ください。
```

リスク：このまま継続すると職員離職・事故リスクが高まります。
選択肢：
  A. 管理者への集中支援を3か月継続し、改善を見届ける
  B. 管理者補佐（サビ管等）を活用し、権限を分散する
  C. 早期に管理者交代を検討する
私の提案：B→Aを並行しつつ、1か月で改善が見られない場合はCへ移行することを推奨します。
SM判断事項：最終的な管理者交代の判断については確認をお願いします。

### 付録E：低稼働施設の改善フロー

```
Step 1：状態の把握
  ├── 入居率・空床日数を確認する
  ├── 退去理由を確認する
  ├── 待機者の有無を確認する
  └── 空床になった経緯を確認する

Step 2：原因の分類
  ├── 営業不足型（紹介ルートが少ない・問い合わせが来ない）
  ├── 受け入れ力不足型（重度対応できない・体制が整っていない）
  ├── 内部問題型（退去が多い・支援の質・職員定着に問題）
  └── 立地・物件型（物件の条件が競合に劣る）

Step 3：改善施策の決定
  ├── 営業不足 → 相談支援への営業強化・紹介先の拡大
  ├── 受け入れ力不足 → 対応可能な障害像の整理・職員研修
  ├── 内部問題 → 管理者・サビ管への集中支援
  └── 立地・物件 → SMへエスカレーション（移転・閉鎖・転換の検討）

Step 4：KPIの設定
  ├── 問い合わせ件数（週次）
  ├── 見学件数（月次）
  ├── 契約件数（月次）
  └── 待機者数（月次）

Step 5：進捗確認
  ├── 週次：AM報告でKPI確認
  ├── 月次：AD横断KPI確認・PL影響確認
  └── 3か月：改善結果を評価・次の施策を判断
```
