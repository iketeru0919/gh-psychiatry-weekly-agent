## 0. この資料の位置づけと使い方

既に手元にある3資料（①方針資料、②新規開設調査、③制度・報酬・運営基準）は
「WHY / RULE / HOW」を押さえるための資料でした。
本資料はそこに欠けていた **4本目＝「EVIDENCE（根拠となる数字と研究）」** です。

用途は3つに絞ってください。

| 用途 | 使う場面 | 本資料の該当章 |

| 代表への提案の説得力を作る | 「なぜこのモデルか」「なぜこの順序か」 | 2章・3章・4章 |

## 1. 【最重要】前提を変える制度・報酬データ

ここは「知識」ではなく **収支の前提が変わる数字** なので最優先です。

### 1-1. 令和8年度（2026年度）報酬改定 ― 新規指定事業所への基本報酬引き下げ

| 項目 | 内容 |
|---|---|
| 就労継続支援B型（新規指定） | 所定単位数の **984/1000**（約1.6%減） |
| 共同生活援助（包括型・日中支援型／新規指定） | 所定単位数の **972/1000**（約2.8%減） |
| 適用開始 | **令和8年6月**〜 |
| 対象 | 施行日以降に**新規指定**を受ける事業所（既存事業所は従来どおり） |
| 除外特例 | 重度障害者の受入れ／サービスが不足している地域での開設 は対象外とされる |

**この数字が意味すること（事業判断への直結点）**

1. 「今から新規で就Bを作る」こと自体が、既存拠点より不利な単価から始まることを意味します。
   収支シミュレーションは **984/1000 の保守ケース** と **既存指定を活用できたケース** の2本立てで作るべきです。
2. **除外特例の2要件（重度受入れ／サービス不足地域）に該当できるかどうか**が、
   モデル地域選定の新しい選定基準になります。
   → 「RASIEL/INNOVELがある地域」だけでなく「B型供給が不足している地域か」を必ず重ねて見る。
3. GH側も972/1000のため、**今後のGH新規開設にも同じ論点が乗ります**。
   代表への説明では「就BとGHの新規開設は、両方とも2026年6月から単価条件が変わった」と
   セットで説明した方が、意思決定の精度が上がります。
4. 行政事前協議の質問リストに以下を必ず追加：
   - 「当該市町村は“サービスが不足している地域”の特例に該当し得るか」
   - 「既存事業所への多機能型追加は、新規指定扱いとなるか」

> 出典：aimari-office / snabi-biz / hugmate / ATLIFE の改定解説（下記6章）
> ※単位数・特例要件は必ず**厚労省告示・通知の原典**で確認してください。

### 1-2. 平均工賃月額と報酬区分

| 年度 | 全国平均工賃月額（B型） |
|---|---|
| 令和5年度（2023） | **23,053円** |
| 令和6年度（2024） | **24,141円**（前年度22,649円との比較記載もあり、要原典確認） |

- 令和6年度改定で **平均工賃月額の算定方法が変更**（分母が「工賃支払対象者数」→「1日あたり平均利用者数」）。
  → **古い年度の工賃数値と単純比較できません。** 既存B型の分析時に必ず注意してください。
- 令和8年度改定で **平均工賃月額の区分基準が引き上げ**（3,000円引き上げとの解説あり）。
  → **同じ工賃実績でも報酬区分が下がりうる**ため、既存拠点の区分シミュレーションを先に回す必要があります。

**平均工賃月額の基本式**
```
年間工賃支払総額 ÷（年間延べ利用者数 ÷ 年間開所日数）÷ 12
```

**事業判断への直結点**
工賃は福利厚生ではなく**翌年度の基本報酬を決める経営変数**です。
法人内業務（BPO）をB型へ発注するモデルは、
「安定した生産活動収入 → 工賃原資 → 報酬区分維持」という
**報酬区分を守るための構造**として説明できます。ここが代表提案での最大の武器になります。

### 1-3. 就労選択支援（令和7年10月〜）

| 項目 | 内容 |
|---|---|
| 開始 | 令和7年10月1日 |
| B型 | 令和7年10月以降、新たにB型利用を希望する者のうち現行の就労アセスメント対象者は**原則として就労選択支援を利用** |
| A型・就労移行（標準利用期間超） | **令和9年4月以降**、原則利用 |
| 例外 | 50歳以上／障害基礎年金1級受給者 等は必須ではなく希望に応じた利用 |

**事業判断への直結点**
- 利用者導線は「ひきこもり→区分取得→B型」ではなく
  **「相談 → 障害福祉サービス対象確認 → 就労選択支援 → 支給決定 → B型」**。
- つまり **モデル地域に就労選択支援事業所が存在するか／どこが担うか** が、
  利用者獲得のボトルネックになり得ます。地域資源調査の必須項目に追加してください。
- 逆に言えば、**自法人で就労選択支援を持つ**ことは強力な入口戦略になり得ます（要検討論点）。

### 1-4. 在宅利用（在宅支援）の要件 ― ここが構想②の生命線

現行運用で求められている主な要件（自治体Q&A・通知ベース）：

- 事業所職員による**訪問・通所・ICT機器（電話/PC等）の活用により、週1回以上**の評価等を実施
- **月の利用日数のうち原則1日は、訪問または通所により事業所内で**訓練目標の達成度評価等を実施
- **市町村が「在宅での支援効果がある」とあらかじめ判断**することが必要
- 運営規程への明記、記録、定期的な評価、**対面が原則**、緊急時対応の整備
- 在宅支援は本来「重度で通所が困難な利用者等」を対象とする趣旨

さらに **令和8年4月13日付 事務連絡「就労移行支援事業、就労継続支援事業（A型、B型）における在宅支援の要件遵守の徹底について」** により、
在宅支援の要件確認・適正化が改めて求められています（不適切ケースの是正）。

**事業判断への直結点（ここは慎重に）**
> 「全国の引きこもりの方に在宅でPC仕事を渡せばB型になる」は成立しません。

- 在宅型モデルは **「制度上できるか」ではなく「この市町村が個別に在宅利用を適当と判断するか」** に依存します。
- したがって **モデル地域決定 → 指定権者・市町村との事前協議** が、物件探しより前に来ます。
- 2026年に要件遵守の徹底通知が出ている以上、**在宅比率が高い設計は運営指導リスクが上がっている**という前提で、
  「通所＋在宅の併用型」を基本設計にするのが安全です。
- 週1回評価・月1回対面という要件は、**支援人員の工数を直接規定します**。
  在宅利用者n人あたり何時間の職員工数が必要かを、収支シミュレーションに必ず織り込んでください。

| 指標 | 数値 | 備考 |
|---|---|---|
| B型事業所数 | 平成27年 9,698か所 → 令和4年 15,748か所（約1.6倍） | 急増市場 |
| 事業所数（別ソース） | 令和6年度報酬改定検証調査の母集団に **25,767事業所** の記載 | 集計基準が異なるため**要原典確認** |
| 利用者数 | 約38万人（2022年度時点の推計） | |
| 利用者の障害種別 | 知的52% / **精神37%** / 身体10% / 難病等1% | 大阪府 令和5年度実績資料 |
| B型からの一般就労移行率 | 約1割（13.2%との記載もあり、資料により幅） | 出口設計の現実値 |
| 生産活動収支 | 一定の基準を満たしていない事業所が **50.7%**（令和5年3月末時点） | 経営改善が課題 |
| 収支差率 | サービス活動収益対増減差額比率 7.8%、黒字事業所は66%（≒約34%が赤字） | 福祉医療機構 2020年度 |

**このデータの読み方 ― 代表への説明で使える論点**

1. **B型は供給過剰気味の成熟市場**です。「拠点数を増やす」だけの戦略は、単価も工賃も下がる方向に働きます。
   → 資料①の結論（「増やすことではなく再現可能なモデルを1つ完成させること」）は、この市場データで裏づけられます。
2. **利用者の37%が精神障害**。つまり、GH（RASIEL/INNOVEL）が精神障害者を主対象としているなら、
   **法人の既存アセットと市場の主要セグメントが一致しています。** これは差別化ではなく「勝ち筋の土台」です。
3. **約3割〜5割の事業所が経営的に苦しい**。参入の是非ではなく、
   「なぜ苦しいのか＝仕事がない／工賃が出せない」という失敗要因が明確です。
   → **法人内業務を先に確保してから開設する**という今回のモデルは、この最大の失敗要因を構造的に回避します。
   ここが代表提案の中核メッセージになります。

## 3. 対象者側の実態データ（ひきこもり・精神障害・GH利用者）

### 3-1. ひきこもり（構想②の市場規模）

| 指標 | 数値 | 出典 |
|---|---|---|
| 全国推計（15〜64歳） | **約146万人**（15〜64歳人口の約2%＝**50人に1人**） | 内閣府 令和4年度「こども・若者の意識と生活に関する調査」 |
| 「誰にも相談したくない」 | 15〜39歳 **22.9%** / 40〜69歳 **18.1%** | 同上 |
| 相談したくない理由（15-39歳最多） | 「相談しても解決できないと思う」**51.5%** | 同上 |
| 就労経験あり | 40〜64歳で **90.3%**、15〜39歳でも6割超 | 同上 |
| ひきこもり地域支援センター | 全都道府県・指定都市（67自治体）に設置済、市町村へ拡充（R7年度 47自治体） | 厚労省 |
| ひきこもり支援ステーション事業 | R7年度 **129自治体** | 厚労省 |
| ひきこもりサポート事業 | R7年度 **164自治体** | 厚労省 |

**このデータの読み方 ― ここが構想②の設計を決めます**

1. **市場規模は十分にあります**（50人に1人）。人口10万人の市なら、単純計算で約2,000人規模。
   → モデル地域の潜在対象者数は「人口 × 2%」で粗く見積もれます。営業資料に使えます。
2. しかし **「相談したくない」層が約2割、その最大理由が「相談しても解決しない」**。
   → **通常の広報・営業では届きません。** 待ちの窓口を作っても人は来ない、というのがデータの結論です。
   → 家族経由・医療経由・行政経由の**間接ルート**の設計が必須。
3. **9割が就労経験あり**（40〜64歳）。
   → 「働けない人」ではなく **「働いた経験があるが、今は職場に行けない人」**。
   これは在宅・低負荷・段階的な仕事設計と相性が良いことを意味します。
   代表への説明でも「就労未経験者を育てる事業」ではなく「就労経験の再起動」と位置づけた方が正確です。
4. 支援ステーション事業・サポート事業の実施自治体数（129・164）は、
   **モデル地域選定の指標**として使えます。実施自治体＝ひきこもり支援に予算と体制を持つ自治体＝連携先が存在する。

## 4. 学術エビデンス（研究論文ベース）

ここは「代表・行政・職員に対して、支援モデルの妥当性を説明する根拠」です。

### 4-1. 就労支援の効果 ― IPS（個別就労支援プログラム／援助付き雇用）

**世界のメタアナリシス（PLOS ONE 2019, RCT 25件）**

| アウトカム | 効果 |
|---|---|
| 一般就労（competitive employment）の獲得 | **リスク比 1.63**（95%CI 1.46–1.82）＝通常支援の約1.6倍 |
| 就労継続期間（job tenure） | d = 0.55 |
| 就労期間（job length） | d = 0.46 |
| 収入 | d = 0.48 |
| QOL | d = 0.30（有意でない） |
| 全般的機能 | d = 0.09（有意でない） |
| 精神症状 | d = 0.03（有意でない） |

**日本での知見**
- 日本でも **3件のRCT**が実施され、うち**2件でIPSに準ずる個別型援助付き雇用の有意性**が示されている（NCNP）。
- IPSモデルの就労率は約55%（従来支援の約2.5倍）との報告。
- 長期追跡のシステマティックレビューでは、IPS利用者の **40〜70%が研究期間中に少なくとも一度は就労を経験**。

**この研究が示す実務上の含意 ― モデル設計に直接効く3点**

1. **「準備してから就労」ではなく「就労しながら支援」が有効**（IPSの中核原則）。
   → 在宅B型モデルでも「訓練が済んでから仕事を渡す」設計にしない。
   **最初から実際の法人内業務を渡し、支援を併走させる**方が、エビデンスに沿っています。
2. **就労支援と生活支援をセットで提供する**のがIPSの原則。
   → **GH（住まい）＋就B（働く場）を同一法人で持つ今回の構想は、IPSの構造そのもの**です。
   これは代表提案で強く使えるロジックです。「思いつき」ではなく「国際的に効果が実証された支援構造と同型」と説明できます。
3. ただし **QOL・症状・機能への効果は有意でない**（d=0.03〜0.30）。
   → **「働けば症状が良くなる」とは言えません。** 職員研修・家族説明では過剰な期待を持たせないこと。
   訴求すべきは「就労・収入・継続」であって「治療効果」ではありません。ここは誠実に線を引くべき点です。

### 4-2. 就労と精神健康 ― 失業のインパクト（Paul & Moser 2009）

横断研究237件・縦断研究87件のメタアナリシス（Journal of Vocational Behavior）：

| 指標 | 数値 |
|---|---|
| 失業者 vs 就業者の心理的苦痛 | **d = 0.51** |
| 心理的問題を抱える割合 | 失業者 **34%** vs 就業者 **16%** |
| 因果性 | 縦断研究・自然実験により、**失業が苦痛を「引き起こす」**ことを支持 |
| 失業者向け介入プログラムの効果 | d = −0.35（中程度の効果） |

**含意**：4-1で「就労は症状を改善しない」と書きましたが、
**逆向き（働けない状態が続くこと自体が心理的苦痛を生む）には因果的証拠があります。**
→ ひきこもり状態への早期の就労機会提供を正当化する、最も強いエビデンスがこれです。
→ 代表への説明ロジックは「働けば治る」ではなく **「働けない状態の長期化が有害である」** とすべきです。

### 4-3. ひきこもりの疫学と精神科的併存

| 知見 | 内容 | 出典 |
|---|---|---|
| 有病率メタ分析（19研究） | 全体 **8.0%**（95%CI 4.9–12.9%）。尺度により大差（HQ-25使用時21.7% vs 他5.0%） | Zhang et al., Psychiatry Clin Neurosci 2025 |
| 生涯の精神疾患併存 | ひきこもり経験者の **54.5%** が気分・不安・衝動制御・物質関連障害の生涯罹患 | Koyama et al. 2010（日本の地域住民調査） |
| 具体的併存 | 社交不安 27%、回避性パーソナリティ 41%、うつ 32% | 日米サンプル |
| 治療の考え方 | 多次元的な支援が必要、**家族支援が非常に重要**というのが広い合意 | レビュー |

**含意 ― これは職員研修と支援設計の根拠になります**

1. **ひきこもり＝怠けではなく、半数以上に精神疾患の併存がある。**
   → 支援体制に**精神科・訪問看護との連携を最初から組み込む**必要があります。
   （＝自法人の精神科領域の知見・週次レポート運用が活きる領域です）
2. **社交不安・回避性が中心的**（27%・41%）。
   → 「通所できない」の本質は移動困難ではなく**対人場面の回避**であることが多い。
   → 在宅就労の設計では、**対人接触の量を段階的に増やせる工程設計**が有効。
   （例：①非同期のチャットのみ → ②音声のみ面談 → ③ビデオ面談 → ④職員訪問 → ⑤月1通所）
   これは在宅支援要件（週1回評価・月1回対面）とも整合します。
3. うつ32%を踏まえ、**作業量・納期のコントロール**は支援上必須。
   → 前章の「納期区分C・D（月末まで／期限なし）の仕事から始める」という方針は、
   臨床的にも妥当です。

### 4-4. 家族支援のエビデンス（CRAFT／ひきこもり家族介入）

- ひきこもり当事者の家族向けに、**MHFA＋CRAFT を基にした3日間介入プログラム**のパイロットRCTが実施
  （Frontiers in Psychiatry 2022／TAU群15名 vs プログラム群14名）。
- 結果：**家族の関わり方の改善に一定の効果が見られる一方、家族の自信の向上には改善余地**があり、プログラム改訂の必要性が指摘されている。
- CRAFT自体は、治療抵抗性の物質使用者を治療につなげる手法として有効性が確立（エンゲージメント率向上）。

**含意 ― 構想②の「入口」はここです**

本人に直接アプローチできない以上、**家族が最初の接点**になります。
CRAFTの発想（家族の関わり方を変えることで本人の相談・受診・利用につなげる）を、
**家族向け相談会・家族会連携**という形で事業に組み込むのが、エビデンスに沿った入口戦略です。
→ 3-1の「相談したくない22.9%」問題への、唯一実証的な回答がこれです。
→ 営業先に **KHJ全国ひきこもり家族会連合会の地域家族会** を必ず入れてください。

## 6. データから導かれる結論（私の判断）

集めたデータを踏まえた、率直な結論です。

### 結論1：構想①（GH連携型）を先に、は データで裏づけられる

- GH入居者の **41.1%が既に就労系サービス利用中**（3-3）→ 初期利用者を確保できる見込みが立つ
- B型の失敗要因は「仕事がない」（2章）→ GH清掃・修繕は**確実に毎月発生する仕事**
- 立ち上がりが速く、検証サイクルが回る

### 結論2：構想②（ひきこもり・在宅型）は「市場は大きいが、入口が最難関」

- 市場：146万人＝50人に1人（3-1）── 十分に大きい
- しかし **相談したくない層が約2割、理由は「解決しないと思う」51.5%**
  → **広報では届かない。家族経由・医療経由の間接ルートしかない**（4-4）
- 在宅利用は市町村の個別判断に依存し、**2026年に要件遵守徹底の通知が出ている**（1-4）
  → 制度リスクが上がっている領域
- **結論：構想②は「設計フェーズに留める」という資料①の判断が、データ的にも正しい。**
  ただし設計内容は変えるべきで、**「在宅就労事業」ではなく「家族支援を入口とした発掘事業」**として設計すべきです。

### 結論3：既存資料に足りていなかった、最も重要な追加論点

**「新規指定＝984/1000」（1-1）は、事業構造の根本に関わります。**

これは単なる1.6%減ではなく、**「新規に作るより、既存指定を活かす方が有利」**という
インセンティブが制度側に組み込まれたことを意味します。したがって代表への提案では、

- 新規B型を作る前に **「既存事業所の多機能型化」「既存指定の活用」が可能か**
- モデル地域を **「サービス不足地域の特例」に該当し得る自治体**から選べないか

の2点を検討したうえで、「それでも新規指定で行く」という結論にする必要があります。
**この検討をしていない事業計画は、代表・行政の双方から必ず突かれます。**

### 結論4：説明の際に、正直に線を引くべきこと

IPSのメタ分析では、**QOL・症状・機能への効果は有意ではありません**（4-1）。
「就労支援をすれば利用者が良くなる」という説明は、エビデンスを超えています。
一方で **「働けない状態の長期化は心理的苦痛を引き起こす」には因果的証拠があります**（4-2）。

提案の言葉は、**「働けば良くなる」ではなく「働けない状態を長期化させない」**にしてください。
これが、データに対して誠実で、かつ最も強い訴求になります。
