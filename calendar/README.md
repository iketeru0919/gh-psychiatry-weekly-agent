# ショートステイ・体験利用 管理表 v5

`dist/ショートステイ管理表_v5.html` を**ダブルクリックで開くだけ**で動きます。
サーバーもインターネット接続も不要です（フォントとReactはファイル内に同梱）。

データは開いたブラウザの localStorage に自動保存されます。旧版（v4）で入力済みの
データがある場合は、初回起動時に自動で引き継がれます。

---

## v4 からの変更点

### 不具合の修正

| 内容 |
|---|
| 初期表示月が `2026-08` で固定されていた。今月を開くようにした |
| 利用者マスタの氏名を直しても既存の予約記録に反映されなかった（区分・送迎は反映されていた）。氏名にも反映するようにした |
| 滞在の入所↔退所の紐付けが「氏名＋部屋」だったため、滞在中の部屋替えや氏名修正で滞在が分断された。`stayId` で紐付けるようにした |
| 重複予約が保存時にブロックされるだけで、復元データや旧形式で入り込んだ重複は画面上どこにも出なかった。カレンダーに警告バッジと件数バナーを出すようにした |
| 稼働率が「利用日数（退所日を含む）÷ 室日」だったため、同日入替のある月で 100% を超え得た。「延べ宿泊数 ÷ 室日」に変更し、定義をカード上に明示した |
| 送迎あり件数が入所・退所の2レコードを別々に数えて倍になっていた。滞在単位に修正した |

### 追加した機能

- **タイムライン表示**（部屋 × 日のガント）。連泊が1本の帯で見える。
  - 帯をドラッグ＝日程移動 / 帯の左右の端をドラッグ＝入所日・退所日の変更 /
    空きトラックをドラッグ＝その期間で新規予約
  - 移動先が重複する場合は移動を取り消して理由を表示
- **空室照会**。期間を入れると空いている部屋を返す。そのまま予約作成へ進める
- **当日の動き**。入所・退所・滞在中・送迎予定と、**食数（朝/昼/夕）の合計**
- **一覧・印刷**表示。月内の利用を明細表で一覧・印刷
- **食事の日別管理**。初日は夕食から、最終日は朝食まで、中日は3食、を既定値として
  日ごとに編集できる（v4 は1滞在に朝昼夕の3フラグしか持てなかった）
- **CSV書き出し** 3種（明細 / 区分別集計 / 食数）。BOM付きUTF-8でExcelがそのまま開ける
- **仮予約・調整中の視覚的区別**（破線表示）と、集計に含めるかの切替
- 月ナビゲーションを「◀ 前月 / 月ピッカー / 翌月 ▶ / 今日」に変更（v4 は18個の横スクロールタブ）
- 「今日」バッジ、備考のツールチップ、標準入所・退所時刻のマスタ化、延泊/短縮ボタン
- スマホ表示対応（月グリッドを1列に、当月以外のセルを非表示）
- 記録ごとの最終更新日時・更新者、および**別端末のバックアップのマージ取り込み**

### 実装していないもの

- **複数端末でのリアルタイム共有**。サーバーが必要なため、単一HTMLでは実現できません。
  代替として「バックアップ保存 →(共有フォルダ等)→ 別端末で"取り込む（マージ）"」の
  運用ができるようにしてあります（同一予約は更新日時が新しい方を採用）。

## 開発

```
node build.mjs
```

`src/template.html`（画面）と `src/logic.js`（ロジック）を、配布用の単一HTMLへ
組み立てます。フォントとReactランタイムは既存の成果物から引き継ぐため、
`dist/` の中身を消してしまうと素材元が無くなりビルドできません。その場合は
元の v4 ファイルを `assets/base-bundle-v4.html` に置いてください。

`src/` はこのプロジェクト独自のテンプレート言語（`sc-for` / `sc-if` /
`sc-camel-on-*` / `{{ }}`）で書かれています。注意点:

- イベントは `sc-camel-on-click` のようにケバブケースで書く（HTMLパーサが属性名を
  小文字化するため、`onClick` は使えない）
- `<table>` 系は `<sc-raw-table>` `<sc-raw-tr>` … を使う。素の `<table>` の中に
  `<sc-for>` を置くと、HTMLのテーブル解析規則で外へ追い出されて行が壊れる
