# シフト週次チェックツール

Dropbox同期フォルダ内の各施設の勤務表Excelを一括解析し、チェック結果をExcelでデスクトップに出力するツールです。ブラウザ版「シフト週次チェック 統合版」(HTML)と同じチェックロジックをPythonに移植し、ファイル選択を自動化したものです。

## できること

- **今回のみチェック**: 常勤者の所定労働時間不足、日中配置数の警告、配置・体制チェック(支援員/世話人の実配置、7.5:1基準、過不足、体制加算判定)
- **前回比較**(2回目の実行から自動): 職員の追加/削除/表記変更、日別の勤務変更・休暇変更、有休/公休数の増減、総労働時間の変化
- **スナップショット**: 実行のたびに勤務表の控えを`_チェック履歴`へ自動保存。上書き運用でも「前回チェック時点との差分」が取れます(対象年月ごとに直近10回分を保持、古いものは自動削除)

## 初回セットアップ(1回だけ)

1. Pythonをインストール — https://www.python.org/downloads/ から最新版を入手し、
   インストール画面で **「Add python.exe to PATH」に必ずチェック** を入れる
2. コマンドプロンプトを開いて以下を実行:

   ```
   pip install openpyxl
   ```

3. このフォルダ一式(`shift_checker`フォルダと`シフトチェック実行.bat`)をPCの任意の場所に置く
4. `shift_checker/config.json` の `base_dir` が実際のシフト管理フォルダのパスと一致しているか確認

## 使い方

1. **`シフトチェック実行.bat` をダブルクリック**
2. 対象年月を入力(例: `2606`)。Enterだけ押すと今月になります
3. 解析が終わると、デスクトップに `シフトチェック結果_2606_YYYYMMDD_HHMM.xlsx` が作成され、自動で開きます

コマンドラインからも実行できます:

```
python -m shift_checker --month 2606
python -m shift_checker --month 2606 --no-snapshot   # 履歴保存と比較をしない
```

## 結果Excelのシート構成

| シート | 内容 |
|---|---|
| サマリー | 施設別の状態(OK/読取エラー)、要確認人数、体制加算判定、過不足、エラー理由、使用ファイル |
| 要確認者 | 全施設の要確認・重要判定の職員(所定不足、時間変化、有休/公休変化、日別変更あり) |
| 職員全件 | 全職員の一覧(フィルタ付き) |
| 日別変更 | 前回比較時のみ。誰のどの日が「前回→今回」でどう変わったか |
| 配置・体制チェック | 施設別の配置・体制チェック値。HTML版の画面と同じ4グループ・同じ項目名(基本情報・体制加算/支援員 配置詳細/世話人 配置詳細/全体基準・過不足) |
| 勤務記号 | 勤務表に登場した全記号と有休/公休の判定区分 |

## エラー・警告の出方

- 書式が違う施設は「読取エラー」として**理由付きでサマリーに赤色表示**され、他の施設の処理は続行します
  - 例: 「管理用シートが見つかりません」「シフト日付列が検出できません」「職員氏名が読めません」「パスワード保護」「旧形式(.xls)」
- 所定不足が80時間を超える職員は「入力途中の可能性」と注記されます
- 同じ施設・同じ月に複数ファイルがある場合は**更新日時が最新のものを採用**し、その旨をサマリーに表示します

## 設定の変更(config.json)

| キー | 意味 | 既定値 |
|---|---|---|
| base_dir | シフト管理フォルダのパス | Dropboxの「1 各施設シフト管理」 |
| output_dir | 結果の出力先(`"desktop"`=デスクトップ) | desktop |
| snapshot_dir | 履歴の保存先(空=base_dir内の`_チェック履歴`) | (空) |
| snapshot_keep | 対象年月ごとに残す履歴の回数 | 10 |
| paid_words / vacation_words | 有休/公休と判定する記号(カンマ区切り) | 有,有休,有給 / 休,公休,希望休など |
| hour_threshold | 総労働時間の変化が何時間以上で要確認にするか | 8 |
| incomplete_threshold | 所定不足が何時間を超えたら「入力途中の可能性」とするか | 80 |
| start_row〜prescribed_cell | 管理用シートの読取位置(テンプレート変更時のみ) | HTML版と同じ |

## 注意事項

- Dropboxの対象フォルダは「**オフラインアクセスを許可**」にしておいてください(「オンラインのみ」のファイルは読み込みに失敗することがあります)
- 結果Excelとスナップショットには職員の氏名・勤務情報が含まれます。取り扱い・保存期間は社内ルールに従ってください
- 勤務表を編集中(未保存)の変更は反映されません。保存後・Dropbox同期後に実行してください
