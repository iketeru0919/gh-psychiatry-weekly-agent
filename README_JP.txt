■ 障害者GH シフト管理アプリ(お試し版)

【準備(初回のみ)】
1. Python 3.11以上をインストール
   https://www.python.org/downloads/
   ※インストール画面で「Add Python to PATH」に必ずチェック

【起動】
Windows: 「start.bat」をダブルクリック
Mac/Linux: ターミナルで ./start.sh

起動後、ブラウザで http://127.0.0.1:5000 を開いてください。

【最初にやること】
1. 「Excel取り込み」にいつものシフトブック(.xlsx)をアップロード
2. 1〜2分待つと「取り込みチェック結果」が表示されます
3. 「この施設を開く」から各タブ(シフト入力/管理ダッシュボード/
   利用者稼働/日次/労務チェック)を操作
4. 労務チェックタブに勤怠CSV・タイミー明細CSVを
   アップロードすると照合が動きます

【データの保存場所】
このフォルダ内の shift_app_data/ に保存されます。
フォルダごとコピーすればバックアップになります。

【複数人で使う場合】
shift_app/README.md の「アカウントと権限」を参照してください。
