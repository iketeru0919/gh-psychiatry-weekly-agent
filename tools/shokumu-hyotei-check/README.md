# 職務評定表チェック(Google Colab)

Google Drive の「職務評定」フォルダ内の Excel(施設別・月別シート)から、
指定した月の 氏名(H列)/順位(I列)/評価(J列)/雇用形態(E列)/入社日(F列)/職種(C列) を抽出し、
施設別に1つの Excel に集約する。あわせて入力エラーを検出する。

## 使い方

`職務評定チェック.ipynb` を Google Colab で開き、①のフォームに対象月
(例: `2026-06`、複数なら `2026-04, 2026-06`)を入力して全セルを実行する。
結果は Drive の `職務評定/チェック結果` に保存される。

## 検出するエラー

- 必須項目(氏名・順位・評価・雇用形態・入社日・職種)の空欄
- 順位の重複・欠番(施設×月単位で 1〜N の連番かを確認)
- 数式エラー(#REF! 等)、評価が想定値(S/A〜F)以外、入社日が日付でない
- 指定した月のシートがどのファイルにも見つからない施設
- B列(手入力の氏名)とH列(評定計算式の氏名)の不一致

## 月の判定

シート名の表記が施設によりバラバラ(`2606` / `2026.6` / `R8.6` / `202606` /
`宮下6月` / `Sheet1` など)なため、各シート内の「評価月」セルの日付を優先して
判定し、シート名は補助的に使う。

## ファイル構成

- `hyotei_check.py` — 抽出・チェック・Excel出力のロジック本体
- `test_hyotei_check.py` — 実ファイルで観測したレイアウトを再現した検証テスト
- `build_notebook.py` — ロジックを埋め込んだ Colab ノートブックを生成
- `職務評定チェック.ipynb` — 生成済みノートブック(配布物)

ロジックを変更したら `python3 test_hyotei_check.py` で検証し、
`python3 build_notebook.py` でノートブックを再生成する。
