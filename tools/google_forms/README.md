# 拠点別 運営状況アンケート(Google Forms 自動生成)

`create_site_survey_form.gs` を Google Apps Script で実行すると、
全40問・12セクションの Google フォームが自動生成されます。

## 手順

1. <https://script.google.com/> →「新しいプロジェクト」
2. `create_site_survey_form.gs` の中身をすべて貼り付けて保存
3. 関数 `createSurveyForm` を選択して「実行」
   - 初回のみ Google アカウントの権限承認が必要です
4. 実行ログ(表示 → ログ)に出る **編集URL / 回答URL** を開く

## 設計方針

| 項目 | 方針 |
| --- | --- |
| 均等目盛 | 全問「5 = 良い状態」に統一。単純平均がそのままスコアとして解釈できる |
| 問5(看護師) | 配置義務のない拠点があるため**必須を解除**し、「配置対象外は空欄で可」と明記 |
| 問13 | チェックボックス、選択数上限 **2つ** |
| 問34 | チェックボックス、選択数上限 **3つ** |
| 問30 | 「あり/なし」ではなく**接点頻度の5段階**。問31(紹介件数)とのクロス集計を想定 |
| 問2 | 記述式(短文)の自由記載。説明文で正式名称での記入を依頼 |
| メール収集 | ON(`setCollectEmail(true)`) |

## 集計時の留意点

- 均等目盛はすべて正方向のため、セクション単位の平均値をそのまま
  「拠点スコア」として扱えます。
- 問30 × 問31 のクロス集計で「接点頻度が高い拠点ほど紹介件数が多いか」を確認できます。
- 問5 の空欄は「看護師配置対象外」を意味するため、平均値算出時は母数から除外してください。
- 問2 は自由記載のため、集計前に拠点名の表記ゆれ(略称・全角半角・旧名称)の
  名寄せが必要です。回答スプレッドシート側に正式名称への変換列を用意しておくと確実です。
