実績記録表_延べ日数抽出ツール
================================

■ できること

Dropbox内の「実績記録表　保存先」配下から、各施設・各月のExcelを探し、
「延べ日数」シートから集計した結果を、1つのExcelファイル（複数シート）に出力します。

出力ファイル: 実績記録表_抽出結果.xlsx

  シート1: サマリー
    実行日時・対象月・対象施設数・各種件数（エラー/確認対象/対象外ファイル）と、
    施設別の合計利用回数を一覧表示します。

    ★ 検算表
    このシートには「検算」表があります。元データ（各Excelの区分別の利用回数）の
    合計と、各集計シートの合計が一致しているかを自動で突き合わせます。
    すべて「OK」なら、集計の途中でデータが落ちていないことが保証されます。
    1つでも「要確認」があれば、確認対象一覧シートにも理由が記録されます。
    まずここを見てください。

  シート2: 施設別・区分別合計（入居）
    施設を行、区分（6・5・4・3・2・1・なし）を列にしたマトリクス形式で、
    入居（1F/2F/3F/日中サービス支援/介護包括）の施設別・区分別の
    合計利用者数を出力します。右端に施設ごとの合計、最終行に全施設の合計が入ります。

  シート3: 施設別・区分別合計（短期）
    シート2と同じマトリクス形式で、短期入所のみを集計します。

  シート4: 施設別・区分別合計（入居＋短期）
    シート2と同じマトリクス形式で、入居と短期を合算して集計します。

  シート5: 施設別合計
    施設名・提供月・区分ごとに、入居1F+2F、入居3F、入居その他、短期、合計を
    横並びで出力します。

  シート6: 区分別_利用回数一覧
    施設名, 棟, フォルダ施設名, 提供月, 種別, ファイル名, 区分, 利用回数, 利用回数合計
    ファイル単位の生データに加え、施設ごとに入居（1F/2F/3F/その他）を合算した
    「入居合計」行も出力します（短期はこの合計には含めません）。

  シート7: 利用者別_延べ日数一覧
    施設名, 棟, 提供月, 種別, ファイル名, 利用者名, 区分, 延べ日数

  シート8: 利用者別_実績詳細
    各ブック内の利用者個票シート（共同生活援助サービス提供実績記録票）から、
    利用者1人＝1行で以下を抽出します。
      受給者証番号, 氏名, 区分, 部屋番号,
      処遇改善加算/重度障害者支援加算Ⅰ・Ⅱ/人員配置体制加算/
      福祉専門職員配置等加算などの加算該当状況,
      合計行の数値（基本算定日数, 住居外利用, 夜勤職員加配加算,
      入院時支援加算, 帰宅時支援加算, 医療連携体制加算, 各種支援加算,
      朝食・昼食・夕食の発注数）,
      入院日数, 外泊日数, 状況内訳
    入院日数・外泊日数は、日別の「サービス提供の状況」欄に
    「入院」「外泊」を含む日を数えたものです（「入院→外泊」のような
    複合値は両方に数えます）。「退院」の日は入院日数に含めません。
    「状況内訳」列に生の内訳（例: 入院開始:1, 入院:10, 退院:1）も
    出力するので、集計定義の確認・検算に使えます。
    ※ この抽出は .xlsx / .xlsm のみ対応です。旧形式（.xls）のファイルは
      スキップされ、確認対象一覧にその旨が記録されます。

  シート9: エラー一覧
    施設名, 提供月, ファイル名, エラー内容

  シート10: 確認対象一覧
    施設名, 提供月, ファイル名, 確認理由

  シート11: 対象外ファイル一覧
    施設名, 提供月, ファイル名, 対象外理由


■ 使い方

1. 「02_実績記録表_抽出実行.bat」をダブルクリックします。
2. 自動でPowerShellが起動します。
3. 見つかった提供月が表示されます。
4. 対象年を入力します。例: 2026
5. 対象月を入力します。例: 6
6. 見つかった施設の一覧が表示されます。対象施設名を入力するか、
   空欄でEnterを押すと全施設が対象になります。
7. 処理が終わると「出力」フォルダに「実績記録表_抽出結果.xlsx」が作成されます。
8. 最後にコンソールへ検算結果（OK / 要確認）が表示されます。
   「要確認」が出た場合は、サマリーシートの検算表と確認対象一覧を見てください。


■ 施設・棟の判定（重要）

このツールは「施設定義テーブル」で施設と棟を判定します。
「01_実績記録表_延べ日数抽出.ps1」の上部にある $FacilityRules がそれです。

  $FacilityRules = @(
      @{ Pattern = "萩丘";   Facility = "萩丘";   SplitUnits = $true;  UnitStyle = "lower"; DefaultType = "" }
      @{ Pattern = "西浅田"; Facility = "西浅田"; SplitUnits = $false; ... }
      ...
  )

  Pattern     ファイル名／フォルダ名に含まれる施設のキーワード
  Facility    集計時に使う施設名（全シート共通）
  SplitUnits  $true  … 棟（ⅰ/ⅱ/北/南）ごとに別施設として集計する
              $false … 棟をまとめて1施設として集計する
  UnitStyle   棟名の表記。"lower"=ⅰ/ⅱ/ⅲ、"upper"=Ⅰ/Ⅱ/Ⅲ
  DefaultType ファイル名から階を判定できないときに使う種別

初期設定では、萩丘だけが棟ごと（萩丘ⅰ／萩丘ⅱ）に分かれ、
西浅田・美田園・白浜町・岩沼・おきつアリーナは1施設にまとまります。

施設を追加したい、棟の分け方を変えたい場合は、ここだけを直してください。
全シートの施設名がここから作られるので、シートごとに数値がズレることはありません。

棟を分けて集計する施設（萩丘）で、ファイル名に棟が書かれていない
短期ファイルなどがあった場合は、どの棟にも寄せず「萩丘(棟共通)」という
独立した行として集計し、確認対象一覧に記録します。
どちらの棟に入れるべきかは自動判断できないため、必要なら
ファイル名に棟（ⅰ/ⅱ）を追記してください。


■ 対象月の指定

初期状態では、実行時に対象年と対象月を入力します。
空欄のままEnterを押すと、見つかった提供月のうち最新年月が入ります。

毎回入力せず、特定の月だけ固定で抽出したい場合は、
「01_実績記録表_延べ日数抽出.ps1」の上部にある

  $TargetMonth = ""

を、以下のように変更してください。

  $TargetMonth = "2026年6月"

使える指定例:

  2026年6月
  2026/6
  202606


■ 対象施設の指定

初期状態では、月の指定に続けて対象施設を対話式で選択します。
施設の一覧が番号付きで表示されるので、対象にしたい施設の番号を入力してください。
空欄のままEnterを押すと全施設が対象になります。

複数の施設をまとめて指定したい場合は、番号をカンマ区切りで入力してください。
全角数字でも入力できます。
（区切り文字は半角カンマ「,」、全角カンマ「，」、読点「、」、空白のいずれも使えます）

  例: 5
  例: 3,12,25
  例: ３、１２、２５（全角でもOK）

番号の代わりに施設名の一部を入力することもできます
（部分一致・大文字小文字を区別しません。例: 美田園,岩沼）。

毎回入力せず、特定の施設に固定したい場合は、
「01_実績記録表_延べ日数抽出.ps1」の上部にある

  $TargetFacility = ""

に、上記と同じ書式で文字列を入力してください（この場合は対話プロンプトは出ません）。


■ Excelファイルの判定

ファイル名から種別を次の順で判定します（上から順に、最初に一致したもの）。

  短期            -> 短期
  3F              -> 入居3F
  2F              -> 入居2F
  1F              -> 入居1F
  日中サービス支援 -> 入居その他
  介護包括        -> 入居その他
  棟の識別子       -> 白浜町Ⅰ=1F / Ⅱ=2F / Ⅲ=3F、美田園北=1F / 南=2F、
                     岩沼ⅰ=1F / ⅱ=2F、西浅田ⅰ=1F / ⅱ=2F
  上記以外        -> 入居その他（集計対象からは外さず、確認対象一覧に記録）

「短期」を最優先で見るため、「短期1F」のようなファイル名でも
入居ではなく短期として集計されます。

種別が判定できないファイルも集計対象から外しません。
「入居その他」として必ず合計に含めたうえで、確認対象一覧に理由を記録します。

実績記録系のキーワードに一致しないファイルは、対象外ファイル一覧シートに出力します。


■ 同じファイルが複数ある場合

「同じ棟」かつ「同じ種別」のファイルが複数見つかった場合のみ、
更新日時が新しい方を採用し、もう一方を確認対象一覧に記録します。

棟が違えば（例: 萩丘ⅰ1F と 萩丘ⅱ1F）、どちらも集計対象になります。


■ 抽出セル

対象シート:

  延べ日数 または 延日数

利用者別:

  対象シートの先頭数行・列を自動でスキャンし、
  「利用者名/氏名/名前」「区分」「延べ日数/延日数」という見出しを探して
  該当する列を使用します。見つからない場合はB列(利用者名)・C列(区分)・
  D列(延べ日数)を既定値として使用し、その旨を確認対象一覧に記録します。

  見出し行より下だけを読み取ります。
  「合計」「小計」「計」などの集計行は利用者として拾いません。

区分別:

  L4:R4: 区分
  L5:R5: 利用回数
  K5: 利用回数合計

  区分の値は表記ゆれを吸収します。
  「６」「区分6」「区分 ６」はすべて "6"、
  「無し」「－」は "なし" として同じ列にまとめます。
  区分が空欄の利用回数は捨てずに「(区分未設定)」列として集計します
  （捨てると合計が元データと合わなくなるためです）。


■ 注意

ExcelがPCにインストールされている必要があります。
（.xlsx / .xlsm の読み取りはExcelを使わず直接行いますが、
  結果ファイルの書き出しと旧形式 .xls の読み取りにExcelが必要です）

Dropboxのファイルが「オンラインのみ」になっていると読めない場合があります。
対象フォルダは、できれば「オフラインで使用可能」にしてください。

他の人がExcelを開いている場合や、Dropbox同期中の場合は読み取りに失敗することがあります。
その場合は「エラー一覧」シートに内容が出ます。

出力先の「実績記録表_抽出結果.xlsx」が既に開かれている場合は、
タイムスタンプ付きの別名で保存されます。
