# グループホーム イノベル磐田 ホームページ

静的HTML（ビルド不要）で構成した1ページ完結のサイトです。

```
site/
├── index.html      # トップページ（全セクション）
├── assets/
│   └── style.css   # スタイル
└── README.md
```

## 表示方法

`site/index.html` をブラウザで開くだけで確認できます。ローカルサーバで見る場合は:

```bash
python -m http.server 8000 --directory site
# http://localhost:8000
```

## デザインの方針

- ベース：NAGI Hotel 的な「白・生成り／大きな写真／たっぷりの余白」
- 質感：明朝体の見出し、ベージュ・グレー・木目に近い自然な配色
- 情報設計：障がい者GHとして必要な項目（暮らし・支援・料金・空室・アクセス・相談）をトップページで完結

セクション順：
ファーストビュー → イノベル磐田について → 3つの特徴 → 暮らし → お部屋・共有スペース
→ 支援について → 1日の過ごし方 → 料金 → ご利用までの流れ → 空室状況 → 施設情報・アクセス → 見学・お問い合わせ

## 公開前に差し替えが必要な箇所

| 箇所 | 内容 |
| --- | --- |
| 写真プレースホルダー（`.photo`） | 居室・リビング・食事・スタッフとの場面・玄関/廊下・周辺環境の実写に差し替え。`<div class="photo">` を `<img>` に置き換えれば比率と余白はそのまま使えます |
| お問い合わせ（`#contact`） | `href="tel:0000000000"` を実際の電話番号に、フォームボタンのリンク先を実際のフォームURLに |
| 受付時間 | 実際の受付時間に |
| 料金表（`#fee`） | 家賃・食費・水道光熱費の金額を公開可能な範囲で記載 |
| 空室状況（`#vacancy`） | 「空室あり／満室」など現況を反映（更新しやすいよう1か所にまとめています） |
| OGP（`<head>`） | 公開URLとOGP画像を設定 |
| 郵便番号・所在地 | 〒438-0086 は仮です。正しい郵便番号を確認のうえ修正してください |

## 実装メモ

- 依存ライブラリなし（JSはヘッダー固定・モバイルメニュー・スクロール表示のみ、素のDOM API）
- `prefers-reduced-motion` に対応（アニメーション無効化）
- スマートフォン〜デスクトップまでレスポンシブ対応
