# 実績記録票 整合性チェックツール（jisseki_check.py）

障害者グループホーム（GH）の実績記録票（xlsm/xlsx）を月次で一括チェックし、
加算の誤算定・算定漏れ・記録不備をExcelレポートとして出力するツールです。
Google Colab から Google Drive 上のファイルに対して実行します。

## Colab での使い方

```python
# セル1：初回のみ
!pip install openpyxl

# セル2：毎回実行
from google.colab import drive
drive.mount('/content/drive')

# セル3：初回のみ
import importlib.util
spec = importlib.util.spec_from_file_location(
    "jisseki_check",
    "/content/drive/MyDrive/実績/jisseki_check.py"
)
mod = importlib.util.module_from_spec(spec)
spec.loader.exec_module(mod)

# セル4：毎月ここだけ実行
mod.run_all(
    "/content/drive/MyDrive/実績",
    "/content/drive/MyDrive/実績/チェックレポート"
)
```

※ Drive 上の `jisseki_check.py` を差し替えた後は、セル3を再実行してください
（Colab はモジュールをキャッシュするため、再実行しないと古いコードのまま動きます）。

## 出力ファイル

```
チェックレポート/
  ├─ 【全GH】チェックサマリー_2026年3月_20260401.xlsx   ← 全施設の横断一覧＋未チェック一覧
  ├─ テスト荘_チェックレポート_2026年3月_20260401.xlsx  ← 施設ごとの詳細（ルール別タブ付き）
  └─ ...（施設ごとに1ファイル）
```

- **【全GH】チェックサマリー**: 📊全施設サマリー（R1〜R22のルール別件数）／施設別シート／⚠未チェック一覧
- **施設別チェックレポート**: ①全チェック一覧／R1〜R22 ルール別タブ／③利用者別サマリー／④チェックルール説明

### ⚠未チェック一覧シートについて

「問題なし」に見えるレポートでも、このシートに載っているファイル・シートは
**検査されていません**。読み取りエラー、様式が想定と異なるシート、
同一フロア・年月の重複ファイルの選別記録（修正版の採用／旧版の除外）がここに集約されます。

## キーワード設定の外部ファイル（チェック設定.xlsx）

施設名などのチェック用キーワードは、コードを変更せずに現場で編集できます。

1. 雛形の作成（初回のみ）: `mod.create_config_template("/content/drive/MyDrive/実績")`
2. 生成された `実績/チェック設定.xlsx` の「キーワード」シートを編集
3. 次回の `run_all` から自動的に読み込まれます（ファイルが無ければ組み込みの既定値を使用）

| 種別 | 用途 |
|---|---|
| 外出キーワード | 備考にあると「住居外利用」とみなす語（R2） |
| 外出除外 | 外出とみなさない語（往診・出前 等） |
| 日中外出先 | 昼食発注の確認対象となる日中サービス・施設名（R5） |
| 昼食発注済み表記 | 昼食確認から除外する語（R5） |
| 退去行先 | 退去日の備考に必要な行先の語（R11） |
| 月跨ぎ記載 | 短期入所の月跨ぎ利用を明示する語（R17） |

| R7 | 外泊開始日の出発時間未記載 | ⚠️ |
| R8 | 入院中の夜勤加配加算 | ❌ |
| R9 | 入院開始・退院・退去日の時間未記載 | ⚠️ |

## 本バージョンでの主な変更点

1. **R17のクラッシュ修正**: 未定義変数 `TSUKI_MATAGIなど_KW` により短期入所ファイルの
   全チェックが「読み取りエラー」として無言でスキップされていた不具合を修正
   （`TSUKI_MATAGI_KW` を定義し、重複していたチェックブロックを削除）
2. **R18・R19・R20・R22 を実装として接続**: 関数だけ存在して一度も実行されていなかった
   4ルールを `run_all` に組み込み（ヘッダー読み取りは1ファイル1回に統合）
3. **レポートの網羅性向上**: 施設別詳細レポートの復活（`build_report` を実際に出力）、
   ルール別タブ・③利用者別サマリー・④説明シートを R22 まで拡張
4. **エラーの区別と可視化**: 「読み取りエラー」と「チェック処理エラー（ツール不具合の可能性）」を
   区別して traceback を表示
5. **キーワードの外部設定対応**: `チェック設定.xlsx` による現場編集（上記参照）
6. **読み取りの安全性向上**: `data_only=True`（数式セルは計算結果を読む）、
   読み取れなかったシート・行を「⚠未チェック一覧」シートに集約
7. **ファイル選別の透明化**: 修正版の採用／除外をログとレポートに記録、
   「修正②」「修正10」等の版数を数値として比較
