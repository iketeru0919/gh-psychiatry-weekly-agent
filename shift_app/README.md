# 障害者グループホーム シフト管理アプリ

Excel(76シート構成のシフト管理ブック)をアプリとして再現するプロジェクト。

## 構成

```
shift_app/
├── xlcalc/          # Excel数式エンジン(数式を読み込みそのまま評価する)
│   ├── parser.py    #   数式トークナイザ+パーサ
│   └── evaluator.py #   評価器(32関数・Lotus互換モード対応)
├── masters.py       # マスタ設定シートからのマスタ抽出(Excel取り込み機能)
├── golden.py        # ゴールデンテスト(全数式セルをExcelキャッシュ値と突合)
└── README.md
```

## 設計方針: 数式エンジン方式

61種の数式パターンを手書きで移植するのではなく、**ブック内の数式を読み込んで
そのまま評価するエンジン**を実装した。利点:

- 施設ごとの数式差分(常勤換算の新旧方式など)を自動で吸収できる
- 「完璧に再現」をゴールデンテストで機械的に証明できる
- 元Excelの様式が更新されても追従しやすい

## ゴールデンテスト

```bash
python -m shift_app.golden ブック.xlsx [シート名...] [--cache=キャッシュDIR]
```

対象シートの全数式セルを評価し、Excelが保存したキャッシュ値と突合する。
TODAY() に依存するセルは比較対象外(実行日で変わるため)。

検証済み: 6施設のブックで 管理用シート・入力シート【現場配布用】・マスタ設定・
★毎月利用日数入力・人員配置【入力用】ほか、**全数式セル一致(不一致0)**。

## マスタ抽出

```bash
python -m shift_app.masters ブック.xlsx [--json]
```

シフト略記号マスタ(記号・開始/終了・休憩・日中h・全体h)と職員マスタ
(職種・従業員番号・氏名・資格・雇用形態)を「マスタ設定」シートから抽出する。
見出しセル探索で位置ずれを吸収し、重複記号・重複氏名は警告として報告する。

## 実装上の重要な発見

1. **管理用シートは Lotus 1-2-3 互換計算モード**
   `sheetPr/@transitionEvaluation="1"` が設定されており、通常のExcel計算規則と
   異なる(`""×数値=0`、`0=""` が TRUE 等)。エンジンはシート単位でこのモードを
   検出して切り替える。これを実装しないと管理用シートの約半数のセルが一致しない。

2. **LibreOffice はこのブックを正しく再計算できない**
   `【】`を含むシート名への参照を破壊するため(24.2系で確認)、LibreOfficeでの
   検証・運用は不可。ゴールデンテストはExcel保存時のキャッシュ値を正とする。

3. **既知の壊れた数式(元Excel側の不具合)**
   管理用シートEF91/EP91(雇用形態別の割増金発生カウント)は `#REF!` を含み
   IFERRORで"0"に落ちている。アプリのUI実装時は本来の意図(EW列を雇用形態別に
   カウント)で再実装する。

## Webアプリ

```bash
pip install -r requirements.txt
python -m shift_app.web            # http://127.0.0.1:5000
```

- **施設一覧**: シフトブック(.xlsx)をそのまま取り込み。施設×月ごとに管理
- **シフト入力**: 職員×日グリッド(記号プルダウン・土日色分け・日勤/夜勤合計)
- **管理ダッシュボード**: 人員配置判定(色分け)・月間KPI・職員別集計・④区分別利用者数の手入力
- **利用者稼働**: 当月利用実態と月別利用日数(区分別平均利用者数の算定)
- **日次**: 日付切替で勤怠実績(出勤者はシフトから自動)+日次チェックリスト
- **Excelエクスポート**: アプリの編集を反映した .xlsx をダウンロード(数式保持)
- **翌月を作成**: マスタ・利用者を引き継ぎ、シフト・日次をクリアした翌月ブックを生成
- **印刷**: 各タブは Ctrl+P で帳票レイアウトになる

### 複数人利用と権限

環境変数でパスワードを設定すると認証が有効になる(未設定なら認証なしのローカルモード):

```bash
SHIFT_APP_ADMIN_PW=管理者PW SHIFT_APP_STAFF_PW=現場PW \
  python -m shift_app.web
```

- **管理者**: 全機能
- **現場**: シフト入力と日次のみ(ダッシュボード・マスタ・取り込み・エクスポート等は不可)

LAN 公開する場合は `flask run --host 0.0.0.0` 相当の起動にし、必ずパスワードを設定すること。
データは `shift_app_data/`(SQLite+アップロード原本)に保存される。
